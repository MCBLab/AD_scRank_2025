# AD_scRank_2025

This project aims to apply gene perturbation modeling using single-cell RNA sequencing (scRNA-seq) data to identify prioritized therapeutic targets and characterize cell-type–specific vulnerability patterns throughout the progression of Alzheimer’s disease (AD).

We use **scRank**, a computational tool designed to simulate gene perturbations in co-expression networks and estimate how different cell types respond to changes in disease-associated genes.

The entire analysis workflow was implemented using **Nextflow**, ensuring scalability, reproducibility, and modularity of the pipeline.
